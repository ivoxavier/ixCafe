Prompt 2: O Mapa de Mesas
Este prompt descreve o ecrã 3, onde o empregado escolhe a mesa.

"Gera um ecrã principal para uma app de restaurante que mostra o mapa de mesas do estabelecimento.

O ecrã deve ter um cabeçalho simples com o nome do restaurante.

O conteúdo principal deve ser uma grelha de cartões que representam as mesas. Cada cartão deve ter um grande número (ex: 'Mesa 01', 'Mesa 02').

Os cartões devem ter estados visuais diferentes:

Um cartão para uma 'Mesa Livre' deve ter um fundo cinzento ou verde claro.

Um cartão para uma 'Mesa Ocupada' deve ter um fundo laranja ou vermelho."
Para android material3
